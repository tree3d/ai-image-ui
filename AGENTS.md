# Codex Project Instructions

- Treat these Git-ignored directories as generated, runtime, dependency, or
  editor data:
  - `logs/`
  - `node_modules/`
  - `dist/`
  - `dist-ssr/`
  - `input/`
  - `output/`
  - `mask/`
  - `crop-stitch/`
  - `uploads/`
  - `.vscode/`
  - `.idea/`
- Do not inspect, search, enumerate, summarize, or edit files under these
  directories unless the user explicitly requests work involving them.
- Treat `.env` and all `.env.*` files except `.env.example` as secrets.
- Never read, inspect, search, summarize, print, or expose their contents
  unless the user explicitly requests it. Never include secret values in
  responses, logs, commits, patches, or command output.
